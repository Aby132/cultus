# Cultus India - Corporate Website

A modern, responsive multi-page website for **Cultus Tradings LLP** - a company specializing in Lightning Protection, Garment Exports, and Global Import-Export Services.

![Cultus India Logo](assets/images/logo.png)

## 🌐 Live Preview

Run on local server: `http://localhost/Cultus/`

## 📁 Project Structure

```
Cultus/
├── index.php              # Homepage
├── lightning.php          # Lightning Protection page
├── garments.php           # Garments Export page
├── trade.php              # Import/Export Services page
├── favicon.png            # Browser favicon
├── includes/
│   ├── header.php         # Reusable navigation
│   └── footer.php         # Reusable footer
└── assets/
    ├── css/
    │   ├── variables.css  # Design tokens
    │   ├── style.css      # Main styles
    │   └── pages.css      # Page-specific styles
    ├── js/
    │   └── main.js        # JavaScript interactions
    └── images/
        └── logo.png       # Brand logo
```

## 🚀 Features

- ✅ **Fully Responsive** - Works on desktop, tablet, and mobile
- ✅ **Modern UI/UX** - Gradients, animations, glassmorphism effects
- ✅ **SEO Optimized** - Meta tags, semantic HTML, proper heading hierarchy
- ✅ **Reusable Components** - PHP includes for header/footer
- ✅ **Smooth Interactions** - Scroll effects, hover animations

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, Flexbox, Grid, Animations
- **JavaScript** - Vanilla JS for interactions
- **PHP** - Server-side includes
- **Lucide Icons** - Modern icon library

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/cultus-india.git
   ```

2. Move to your web server directory (e.g., XAMPP htdocs):
   ```bash
   cp -r cultus-india /path/to/htdocs/Cultus
   ```

3. Start Apache server and navigate to:
   ```
   http://localhost/Cultus/
   ```
